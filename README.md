# Ajinkya Shinde – Portfolio

Welcome to my personal portfolio website.  
I’m **Ajinkya Shinde**, a **Web Developer** and **Computer Technology student** from India.  
This site showcases my skills, projects, GitHub activity, and ways to contact me.

---

## 🚀 Features

- **Modern, responsive UI** – Works smoothly on mobile, tablet, and desktop.
- **Hero Section with About** – Clear introduction, role, and goals.
- **Project Showcase** – Live demos + GitHub links with short case-study style descriptions.
- **Tech Stack Tabs** – Separate tabs for languages, tools, and frameworks.
- **GitHub Stats Integration** – Overview, streak, top languages, and trophies.
- **Contact Form with EmailJS** – Messages go directly to my email.
- **SEO Optimized** – Meta tags, Open Graph tags, and clean structure.
- **Performance Touches** – Lazy-loaded images and IntersectionObserver based animations.
